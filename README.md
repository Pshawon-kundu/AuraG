# AuraG

AuraG is a responsive skill-based Web3 gaming landing page built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Mobile-first layout with a desktop dashboard-inspired presentation
- Designed for the AuraG pre-launch marketing site
- The waitlist CTA currently points to a placeholder email address
